## 5. 技术硬约束

1. **零构建、零 CDN、零框架**：原生 JS + CSS + 手写 SVG。
2. **同源**：页面与 API 同端口，不需要 CORS。
3. **中文注释**，说明「为什么」而不是「做什么」；与现有代码风格一致。
4. **API 契约不变**：不删字段、不改语义、不改路径；新增字段只能是可选追加，且非必要不加。
5. **前端资源一律绝对路径** `/assets/…`（页面在 `/m/` 下，相对路径会解析成 `/m/assets/…`）。
6. **移动端规范**：`viewport-fit=cover`、`env(safe-area-inset-*)`、`100dvh`、
   `input` 字号 ≥ 16px、可点区域 ≥ 44×44px、`-webkit-tap-highlight-color: transparent`。
7. **路由**：hash 路由（`#/market`、`#/watch`、`#/alerts`、`#/health`、`#/a/{ammo_id}`），
   安卓返回键可关闭详情层。
8. **布局**：<600px 单列；≥600px 居中最大 560px；横屏不崩即可，不做专门布局。
9. **配色**：只用现有 CSS 变量（红涨绿跌），不新增色板。
10. **性能预算**：`mobile.js` ≤ 40KB、`mobile.css` ≤ 15KB、首屏 2 个请求、无图片/字体请求。
11. **安全**：token 走 `X-Auth-Token` 请求头；静态资源不拦；本机回环免 token。
12. **不改启动方式**：手机访问用一体模式（`-Lan` 强制一体模式，禁止 `-Dev` 用于手机）。

## 6. 已知易错点（写代码前逐个核对）

| # | 易错点 | 正确做法 |
| --- | --- | --- |
| 1 | `percentile_7d` 被当成 0~100 | 它是 **0~1 小数**；显示为 `Math.round(v*100)+"%"` |
| 2 | 把 `source_index_7zf` 当涨跌幅 | **定义未知，不参与任何计算**；展示时必须标注，或干脆不展示 |
| 3 | 用 `price` 当单发价 | `price` 是原始价，`unit_price` 才是折算单发价；两者都展示 |
| 4 | 用 `name` 当唯一键 | 唯一键是 `ammo_id`；同名不同品质是不同物品 |
| 5 | 时间戳单位搞错 | `price_ts` / `updated_at` 是 **Unix 秒**，不是毫秒 |
| 6 | 以为要自己加静态路由 | `StaticFiles(html=True)` 已挂 `frontend/`，`/m/` 自动生效，**不改后端路由** |
| 7 | 改 `.env` 想绑 0.0.0.0 | `start.ps1` 写死了 `--host 127.0.0.1`，必须走 `-Lan` 参数 |
| 8 | 用 `-Dev` 模式做手机测试 | `serve_frontend.py` 反代会绕过 token；手机必须一体模式 |
| 9 | 忘了回环免 token | 开启 token 后本机（127.0.0.1/::1）必须免 token，否则桌面端废掉 |
| 10 | 静态资源也被 token 拦了 | `/m/`、`/assets/`、manifest、favicon 必须放行，否则登录页加载不出来 |
| 11 | 给 HTTP 页面注册 Service Worker | 非安全上下文必然失败；v1 **不写 SW** |
| 12 | 用 `100vh` 做全屏 | 安卓地址栏伸缩会裁切，用 `100dvh` 并给回退 |
| 13 | 详情层用 `display:flex` 压过 `[hidden]` | 项目曾因此出现"关不掉的抽屉"，见 `tests/test_frontend_css.py`；用 `hidden` + `display:none !important` 或统一 class 控制 |
| 14 | 前端相对路径 | `href="/assets/mobile.css"`，不是 `assets/mobile.css` |
| 15 | 图表点太多卡顿 | 30d 数据先降采样到 ≤ 300 点再绘制 |
| 16 | 手机端页面被桌面样式污染 | 移动端独立 CSS，不引入 `style.css`（按需复制 token） |
